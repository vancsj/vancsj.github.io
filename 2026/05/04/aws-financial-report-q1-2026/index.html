AWS 2026 Q1 财报：营收 376 亿，芯片手握 2250 亿订单

发表于 2026-05-04 更新于 2026-09-07 分类于 AWS ， 云计算 ， 财报分析 阅读次数：

5 月 4 日 Amazon 发布 2026 Q1 财报，AWS 营收 376 亿美元，同比增长 28%。这是 15 个季度以来最快的一次。

过去两年大家习惯的叙事是 AWS 增速见顶、被 Azure 和 Google Cloud 甩开。这个季度它自己把这条线拉了回来。

AWS Q1 核心数据

  • 营收: 376 亿美元，同比增长 28%
  • 运营利润: 142 亿美元，利润率 37.7%
  • 年化营收: 1500 亿美元
  • AI 业务: 年化收入超过 150 亿美元，三位数增长
  • 自研芯片业务: 年化收入超过 200 亿美元
  • 在手订单: 3640 亿美元（不含 Anthropic 那笔）

28% 这个数字的分量在于基数。1500 亿的年化规模上还能跑出 28%，Andy Jassy 在电话会上说这种情况很少见。

利润率 37.7%，在整个科技行业属于顶级水平。

AI 相关服务的年化收入已经超过 150 亿美元，还在三位数增长。它现在是 AWS 里增速最快的部分，但相对 1500 亿的总盘子仍然只占一成。

芯片才是这份财报里最硬的数字

从 2018 年起 AWS 就在铺 AI 基础设施，最早是 SageMaker，之后不断加服务。但这一轮真正拉开身位的是自研芯片。

AWS 有两条线：Trainium 针对大模型训练，Graviton 做通用计算，已经到第四代，性价比上对 Intel 和 AMD 有明显优势。

芯片业务的年化收入超过 200 亿美元。更值得看的是订单：Trainium 的收入承诺累计超过 2250 亿美元。Trainium2 基本售罄，性价比比同级 GPU 好约 30%；Trainium3 在 2026 年初开始出货，比 Trainium2 又好 30% 到 40%，目前也接近订满。

作个参照，Nvidia FY2025 数据中心营收 1152 亿美元，FY2026 涨到 2159 亿。AWS 的 200 亿还差得远，而且口径不同：它主要按内部使用计价，不是对外卖芯片。但 2250 亿的承诺是签出去的，那是未来几年的确定性收入。

三家云都在加速，AWS 是最慢的那个

厂商 Q1 2026 营收 增速 利润率
AWS 376 亿美元 28% 37.7%
Google Cloud 200 亿美元以上 63% 32.9%
Microsoft Azure 未单独披露 40% 未单独披露

Google Cloud 首次突破 200 亿美元，增速 63%，运营利润从去年同期的 22 亿涨到 66 亿，利润率翻了近一倍到 32.9%。这已经是它连续第三个季度加速：2025 年 Q2 是 32%，Q3 是 34%，Q4 是 48%。

Azure 连续三个季度维持在 39% 到 40%，微软的 AI 业务年化收入突破 370 亿美元。微软不单独披露 Azure 的绝对营收，所以表里只能放增速。

全球云基础设施市场 Q1 2026 规模 1290 亿美元，同比增长 35%，是连续第九个季度增速上升。三家一起加速，说明 AI 需求是把整个盘子做大了，不是在彼此之间搬份额。

按份额算，AWS 约 28%，Azure 约 21%，Google Cloud 约 14%（不同机构口径差异不小，有的把 AWS 算到 31%）。

所以 AWS 增速最慢这件事要分两面看。63% 对 28%，Google Cloud 快得多；但 AWS 的基数是它的近两倍，单季度多出来的绝对金额仍然更大。

服务构成：EC2 占一半以上

AWS 从不公布服务级别的营收构成。按 analyst 估计，EC2 仍然占 AWS 营收的 50% 以上。

这不难理解。EC2 是起家业务，也是云计算的底层。AI 训练、大数据处理、网页托管，都要先有计算资源。

其他主要服务的估算占比：

  • S3 + EBS（存储）: 约 15-20%
  • RDS（数据库）: 约 10%
  • 其他（Lambda、API Gateway 等）: 约 15-20%

EC2 的利润率 analyst 估在 55% 左右，这是 AWS 整体能维持在 37.7% 的主要原因。

地区分布：这组数字是 Amazon 全公司的

从 2025 年 10-K 看，Amazon 全公司的收入地区分布：

  • 美国: 4897 亿美元（68%）
  • 德国: 459 亿美元（6.4%）
  • 英国: 432 亿美元（6.0%）
  • 日本: 307 亿美元（4.3%）
  • 其他地区: 1075 亿美元（15%）

五项合计约 7170 亿美元，是 Amazon 全公司的规模，其中绝大部分来自零售。AWS 全年营收 1500 亿左右，占不到零头。10-K 按这五个地区披露的是全公司净销售额，AWS 自己的地区拆分 Amazon 从不单独公布。

所以从这组数字只能读出一件事：Amazon 的收入高度集中在美国本土。AWS 在海外的占比是多少，这份财报回答不了。

风险：钱正在以前所未有的速度出去

Amazon 给的 Q2 指引：

  • 营收: 1940-1990 亿美元，同比增长 16% 到 19%
  • 运营利润: 200-240 亿美元

Q1 的运营利润是 239 亿，所以指引中位数意味着环比可能下滑。Amazon 点了两个原因：Q2 有年度股权激励的季节性上升，另外 Leo 卫星制造成本会带来约 10 亿美元的同比逆风。Jassy 还提到内存和存储的元器件价格涨得很凶。

更值得盯的是现金。Q1 的现金资本开支 432 亿美元，主要投在 AWS 和生成式 AI。滚动十二个月的自由现金流从 259 亿掉到 12 亿，因为固定资产采购同比多了 593 亿。BofA 在财报后的报告里预计 2026 和 2027 两年自由现金流都会是负的。

Q1 净利润 303 亿美元，但这里面有 Anthropic 相关的投资收益。看经营质量要看 239 亿的运营利润，不是净利润。

我的看法

这份财报里最容易被忽略的是那个 2250 亿。

营收和增速是过去一个季度的结果，会随需求波动。2250 亿的 Trainium 收入承诺是已经签下来的未来几年收入，而且客户在 Trainium3 出货前就把产能订得差不多了。这说明 AWS 的自研芯片已经不是省成本的内部项目，是有人排队买的产品。

至于增速，28% 好看，但它是三家里最低的，而且 Google Cloud 63% 的势头看上去还没到顶。AWS 靠的是基数、利润率和订单深度，不是速度。

真正的问题在现金流。滚动十二个月自由现金流只剩 12 亿，资本开支单季度 432 亿。这个投入节奏能撑多久，取决于那 3640 亿在手订单转化成收入的速度。下个季度看这两个数字的比值，比看营收增速有意义。

数据说明：本文数据来源于 Amazon 2026 Q1 earnings release（2026 年 5 月 4 日）、2025 10-K filings、Alphabet 与 Microsoft 的同期财报披露、NVIDIA FY2025/FY2026 财报。部分服务级别的占比为 analyst 估计，Amazon 从不披露此类细节。云市场份额为第三方机构估算，各家口径不一。
